# Instruções do repositório

- Trabalhe no checkout e na branch atuais; não crie nem use git worktrees.
- Nesta fase do projeto, não crie, altere ou execute testes unitários. Valide mudanças com verificações não unitárias adequadas, como typecheck, lint, build e validação manual quando aplicável.
- Incluir JS Doc para todas funções implementadas.
